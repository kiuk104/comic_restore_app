# 이북 본문 편집 기호 참조

검수 페이지(PC 편집 서버 / 폰 클라우드 검수)의 원문·번역 칸에서 쓰는
기호 정리. 출력(TXT/EPUB) 반영은 [📖 TXT/EPUB 재생성] 시점.
(v0.13.4 기준 — 검수 페이지의 필터 메뉴 맨 아래 "❓ 기호 도움말"에서도 볼 수 있음)

## 구조 기호 (줄/문단 단위)

| 기호 | 위치 | 효과 |
|---|---|---|
| `## ` | 문단 맨 앞 | 제목/소제목 — EPUB 장 분할·목차 기준. [§ 제목] 버튼과 동일 (버튼이 자동으로 붙이고 뗌) |
| `>> ` | 줄 맨 앞 | **그 줄만** 오른쪽 정렬 (헌사·서명·날짜용). 전각 `＞＞`, 앞 공백 있어도 인식. 뒤에 공백 필수 |
| 엔터 1회 | 문단 안 | 줄바꿈 유지 (EPUB `<br/>`) — 헌사처럼 행 구분이 있는 문단 |
| 빈 줄 | 문단 안 | **번역 칸만** 세로 여백으로 유지 (연속 빈 줄은 1개로 정리). **원문 칸은 자동으로 축약됨** — 원문 검수 파일의 문단 구분(빈 줄)과 충돌하기 때문 |

## 글자 서식 (인라인 — 쌍으로 감싸기)

| 입력 | 출력 |
|---|---|
| `**굵게**` | **굵게** |
| `*기울임*` | *기울임* |
| `~~취소선~~` | ~~취소선~~ |
| `++밑줄++` | 밑줄 |

- 여는 기호와 닫는 기호가 **쌍**이어야 변환됨 — 홀수 개(각주 `*` 등)는 문자 그대로 출력되므로 안전
- TXT 출력·목차에서는 기호가 제거된 플레인 텍스트로 나감
- 👁 미리보기·📖 읽기 모드에서 실제 서식으로 미리 확인 가능

## 특수 동작

| 동작 | 효과 |
|---|---|
| 번역 칸 비우기 | 그 문단은 **원문 그대로** 출력 (표지·저작권 페이지 등) |
| 페이지 [↩ 원문] | 해당 페이지 전체 문단의 번역을 한 번에 비움 |
| 페이지 [🖼 표지] (PC 전용) | 그 페이지 스캔을 EPUB 표지로 지정 (기본은 첫 페이지 자동) |

## 예시 — 헌사 페이지

입력(번역 칸):

```
사랑을 담아, TJ

>> C. 브레네 브라운
>> 1984년 10월 9일
```

출력: "사랑을 담아, TJ" 왼쪽, 한 줄 여백, 서명·날짜 두 줄은 오른쪽 정렬.

취소선 예시: `당신은 나를 ~~모른다~~.` → 당신은 나를 ~~모른다~~.
