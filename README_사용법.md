# 스캔 만화 복원 파이프라인 (v2 보정 + v3 재조판)

## 통합 앱 (권장) — `comic_restore_app.py`

원본 폴더 지정 → Upscayl(digital-art) 업스케일 → 한글 재조판 → 출력 폴더까지 한 번에:

```powershell
python comic_restore_app.py
```

- Upscayl 설치 경로(`upscayl-bin.exe`, models 폴더)는 자동 감지됨 (없으면 직접 지정)
- 최종 배율 선택 가능 (모델은 4x로 처리 후 지정 배율로 리사이즈 — 기존 `digital-art-4x_2x`와 동일)
- "업스케일 건너뛰기" 체크 시 이미 업스케일된 폴더를 바로 재조판
- API 키는 앱에 입력 ("키 저장" 체크 시 `app_config.json`에 저장 — 공용 PC에선 끄기)
- **폰트 프리셋**: 드롭다운에서 만화 식자용 폰트 선택 (설치된 것만 표시됨)
  - **자동 매칭 (원본과 유사한 폰트)**: 페이지의 글자 획 굵기·명조/고딕 대비를 분석해 설치된 프리셋 중 가장 비슷한 폰트를 자동 선택. 로그에 후보 3개와 차이값 표시
  - 자동 감지 (기본): 나눔명조 Bold → 바탕체 순으로 자동 선택
  - 추가 프리셋: KoPub 바탕 Bold(출판 명조), 함초롬바탕, 검은고딕(외침), 배민 도현체·을지로체, 잘난체 — 설치 시 자동 표시 (눈누 noonnu.cc에서 다운로드)
  - 인쇄체 대사: 나눔명조 Bold(추천) / 바탕체(옛날 인쇄 만화 느낌)
  - 고딕 대사: 나눔고딕 ExtraBold·Bold / 나눔바른고딕 / 맑은 고딕
  - 특수: 궁서체(사극·비장한 대사), 돋움체(구형 식자)
  - 손글씨: 나눔붓(추천) / 나눔펜 / 나눔바른펜
  - "직접 지정" 선택 후 경로 칸에서 아무 ttf/otf/ttc나 지정 가능
- **샘플 미리보기**: 샘플 번호(N번째 장)를 정하고 [샘플 미리보기] 클릭 → 그 한 장만 처리 후 미리보기 창이 뜸. 이미지를 클릭(또는 스페이스)하면 원본↔결과 전환 비교. 샘플 결과는 `출력폴더\_sample`에 저장. 만족스러우면 [전체 시작]
- **미리보기에서 실시간 폰트 교체**: 미리보기 창 상단의 폰트 드롭다운에서 다른 프리셋을 고르면 **API 재호출 없이 1~2초 내** 그 폰트로 다시 조판된 결과가 표시됨 (전사·레이아웃은 캐시 재사용). 마음에 드는 폰트를 찾은 뒤 메인 창 프리셋에 반영하고 전체 실행
- "테스트 장수"에 3을 넣고 먼저 돌려본 뒤 0(전체)으로 본 작업하는 방법도 있음
- 중간에 "중지" 버튼으로 취소 가능, 업스케일 결과는 `출력폴더\_upscaled`에 캐시되어 재실행 시 건너뜀

### 실행파일(.exe) 만들기

`build_exe.bat` 더블클릭 → `dist\ComicRestore.exe` 생성 (1~3분 소요).

- 최초 1회만 빌드하면 이후엔 파이썬 없이 exe만 실행하면 됨
- 설정(`app_config.json`)은 exe 옆에 저장됨
- exe를 다른 폴더로 옮겨도 동작 (단, Upscayl·폰트는 별도 필요)
- 백신이 오탐하면 예외 등록 (PyInstaller 단일파일 exe의 흔한 오탐)

아래는 각 단계를 개별 스크립트로 쓰는 경우의 설명.

두 단계 도구입니다. 상황에 맞게 선택하세요.

| 스크립트 | 방식 | 언제 쓰나 |
|---|---|---|
| `comic_restore_pipeline.py` (v2) | 비파괴 톤 보정 — 지우지 않고 원본 글자를 선명하게 | 원본 글자가 그럭저럭 읽히는 페이지 |
| `comic_retype_pipeline.py` (v3) | Claude API로 열화 한글 전사 → 지우고 나눔명조 재조판 | 원본 글자 자체가 심하게 깨져 가독성이 낮을 때 |

v3는 v2 보정을 베이스로 깔고 그 위에서 재조판하므로, v3만 돌려도 페이지 전체가 함께 보정됩니다.

# v3 — 말풍선 한글 재조판 (Claude API)

## 원리

1. v2 톤 보정 → 2. 글자 블록 감지 (말풍선 형태 추정이 아니라 흰 배경 위 글자 클러스터를 직접 찾음) → 3. 블록 크롭을 Claude 비전에 전송, 한국어 문맥으로 깨진 글자 복원 전사 → 4. **dialogue + high 확신도만** 글자 획 주변을 정밀하게 지우고 나눔명조 Bold로 재조판 (하이브리드 정책)

레이아웃 정합 (원본 조판 재현):
- 감지 단계에서 원본 글줄 밴드(줄별 위치·높이)를 저장하고, 전사도 원본 줄바꿈을 보존
- 폰트 크기는 **원본 글줄 높이 기준**으로 결정 (한글 줄들의 높이 맞춤 크기 중앙값, 블록당 단일 크기)
- 줄 폭이 원본보다 8% 이상 넓어지면 크기를 줄이는 대신 **자간 압축(최대 12%)**으로 해결 → 크기가 원본과 달라지지 않음
- 각 줄은 원본 줄의 중심 좌표에 렌더링. 줄 수 불일치 시 자동 맞춤(bbox 중앙 정렬)으로 폴백
- Text 레이어는 픽셀(래스터) 레이어로 저장되므로 포토샵에서 폰트 없이 바로 열림

손글씨 대사 재현 (기본 꺼짐, 옵트인):
- Claude가 손글씨 대사·메모·쪽지를 `hand`로 분류. **기본값은 보존(재조판 안 함)**
- 재조판하려면 `--retype-hand --hand-font "...\NanumBrush.ttf"` 두 옵션을 함께 지정
- 줄 간격이 붙은 큰 손글씨는 밴드가 하나로 잡혀도 전사 줄 수대로 균등 분할해 배치
- 손글씨 폰트가 원본 붓글씨보다 가늘어 1px 스트로크 자동 보강
- 추천 폰트: 나눔손글씨 붓(NanumBrush.ttf)·나눔펜(NanumPen.ttf) — 나눔글꼴 전체 패키지(nanum-all)에 포함

안전장치:
- 확신 없는 말풍선은 지우지 않고 v2 보정 상태 유지 → `review.json`에 기록되어 수동 확인 가능
- 제목·로고 등 장식 텍스트(display)와 효과음(sfx)은 그림의 일부로 취급해 재조판하지 않음
- 지우기는 글자 획 주변 7px만 — 말풍선 테두리·그림 선은 구조선 보호로 침범 불가
- 재조판 폰트 크기는 원본 글자 크기 기준으로 상한 → 원본 조판 느낌 유지

## 출력물 (v3)

| 파일 | 내용 |
|---|---|
| `<파일명>.psd` | Background / Restored(v2 보정) / BubbleClear / **Text01~NN (말풍선별 개별 레이어)** |

| `review.json` | 말풍선별 전사 텍스트·확신도·재조판 여부·`pos_overlap`(위치 QC) |
| `_debug/*_detect.png` | (--debug) 초록=재조판, **마젠타=위치 확인 필요**, 주황=전사만 됨, 빨강=텍스트 없음 |

### 위치가 어긋난 대사 교정 (포토샵)

- 실행 로그에 `!! 위치 확인 필요 N건`이 뜨면 `review.json`에서 `pos_overlap > 0.03`인 항목 확인 (글자 잉크가 흰 배경이 아닌 곳에 겹친 비율)
- 텍스트가 말풍선별 **개별 레이어(Text01~NN)** 라서, 포토샵에서 해당 레이어를 이동툴(V)로 끌어 옮기기만 하면 됨. 크기 조절도 레이어 단위 자유변형(Ctrl+T)으로 가능
- 어떤 레이어가 어떤 대사인지는 review.json의 재조판 순번(retyped=true 순서) = Text 번호

# v2 — 비파괴 화질 복원 파이프라인

Upscayl 업스케일 후 **말풍선 안 한글 획이 회색으로 열화되는 문제**를 복원하는 스크립트.

## v1과의 차이 (전면 재설계)

v1(`comic_bubble_pipeline.py`)은 말풍선을 지우고 OCR로 다시 쓰는 구조였는데, 열화된 스캔에서 Tesseract 인식률이 낮아 대사가 통째로 지워지거나 오독된 텍스트가 얹히는 문제가 있었습니다.

v2는 **아무것도 지우지 않습니다**. 열화된 획이 실제로는 중간 회색(밝기 75~150)으로 남아 있다는 점을 이용해, 톤 매핑으로 원본 글자 자체를 검게 되살립니다.

- 대사 소실 구조적으로 불가능 (픽셀을 지우는 단계가 없음)
- OCR 없음 → 오독 없음, Tesseract·폰트 설치 불필요
- 그림 영역(스크린톤·그라데이션·어두운 표지)은 자동으로 보호됨

## 처리 원리

1. **조명 평탄화** — 종이 얼룩·조명 불균일 제거. 배경 추정을 클램프해서 어두운 그림/표지는 건드리지 않음
2. **노이즈 제거** — 업스케일 아티팩트 완화
3. **이중 톤 커브** — 그림엔 완만한 커브, 글자 영역엔 강한 S커브(회색 획→검정) + 획 두께 보강
4. **화이트니스 마스크** — 주변이 대부분 흰색인 곳(말풍선·캡션)에만 강한 커브를 페더링 블렌딩

## 설치

```powershell
pip install opencv-python numpy pillow psd-tools
```

## 사용법

```powershell
# 먼저 3장 테스트 (원본|보정 비교 이미지 포함)
python comic_restore_pipeline.py --src "원본폴더" --out ".\test_v2" --limit 3 --debug

# 전체 처리
python comic_restore_pipeline.py `
    --src "D:\i\comics\도박묵시록 카이지\도박묵시록 카이지 01\upscayl_png_digital-art-4x_2x" `
    --out "D:\i\comics\도박묵시록 카이지\도박묵시록 카이지 01\restored_v2"

# PNG만 빠르게 (PSD 생략)
python comic_restore_pipeline.py --src "..." --out "..." --no-psd --no-denoise
```

## 출력물

| 파일 | 내용 |
|---|---|
| `<파일명>.psd` | 2-레이어: `Restored`(보정) / `Background`(원본). Restored를 끄면 원본 그대로 → 비파괴 |
| `<파일명>_restored.png` | 보정 완료 이미지 |
| `_debug/<파일명>_compare.png` | (--debug) 원본\|보정 좌우 비교 |
| `run.log.json` / `failed.log` | 처리 로그 / 실패 목록 |

## 튜닝

| 옵션 | 기본 | 설명 |
|---|---|---|
| `--text-black` | 80 | 글자 커브 검정점. 글자가 여전히 흐리면 90~100 |
| `--text-white` | 210 | 글자 커브 흰점. 낮추면 배경이 더 하얘짐 |
| `--thicken` | 0.5 | 획 두께 보강(0~1). 가는 획이 끊겨 보이면 올림 |
| `--paper` | 215 | 종이 밝기 하한. 어두운 스캔이면 200 |
| `--no-denoise` | — | 노이즈 제거 생략, 약 3배 빠름 |

## 한계

- 획이 회색으로라도 남아 있어야 복원됨. 완전히 지워진 획은 생성 없이 복원 불가 → 해당 부분만 포토샵에서 수동 보필
- `test_v2/` 폴더에 8장 샘플 결과와 `_비교_글자복원.png`(비포/애프터) 있음
